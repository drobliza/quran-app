# 📖 Quran App

تطبيق ويب بسيط باللغة العربية مبني باستخدام **Node.js** و**Express** و**SQLite** و**bcrypt**. يوفر نظام تسجيل وإنشاء حسابات وتسجيل دخول، ثم يتيح للمستخدم المسجل الوصول إلى صفحة القرآن.

## ✨ المميزات

- 🔐 تسجيل المستخدمين وتسجيل الدخول.
- 🔑 تشفير كلمات المرور باستخدام `bcrypt` قبل تخزينها.
- 👤 جلسات تسجيل دخول باستخدام `express-session`.
- 🗄️ قاعدة بيانات SQLite لتخزين المستخدمين.
- 📖 صفحة قرآن محمية لا يمكن الوصول إليها بدون تسجيل الدخول.
- 🚪 تسجيل الخروج وإنهاء الجلسة.
- 🌐 واجهة HTML موجودة داخل مجلد `views`.

## 🛠️ التقنيات المستخدمة

- Node.js
- Express 5
- SQLite3
- bcrypt
- express-session
- body-parser

## 🚀 التشغيل

### 1. تثبيت Node.js

تأكد من تثبيت Node.js وnpm.

### 2. تثبيت الاعتمادات

```bash
npm install
```

### 3. تشغيل التطبيق

```bash
node app.js
```

بعد التشغيل سيكون الخادم متاحًا افتراضيًا على:

```text
http://localhost:3000
```

ويستمع التطبيق على المنفذ `3000`. fileciteturn41file0

## 👤 الحسابات

عند تشغيل `db.js` لأول مرة، ينشئ التطبيق جدول `users`، كما يحتوي الكود الحالي على إنشاء مستخدم افتراضي باسم `admin`. fileciteturn42file0

**تنبيه أمني:** كلمة المرور الافتراضية الموجودة حاليًا في الكود هي `1234`. يجب تغييرها أو إزالة الحساب الافتراضي قبل استخدام التطبيق في بيئة حقيقية.

## 🔐 ملاحظات أمنية

هذا المشروع مناسب للتجارب والتطوير، لكنه يحتاج إلى بعض التحسينات قبل نشره على الإنترنت:

- نقل `secret` الخاص بـ `express-session` إلى متغير بيئي بدل وضعه مباشرة في الكود.
- عدم وضع كلمات مرور افتراضية داخل المصدر.
- عدم رفع قاعدة البيانات `users.db` إلى مستودع عام إذا كانت تحتوي على بيانات مستخدمين حقيقية.
- استخدام HTTPS عند النشر.
- إضافة إعدادات آمنة للـcookies والجلسات.
- إضافة حماية مناسبة من CSRF ومحاولات تسجيل الدخول المتكررة.

حاليًا يستخدم التطبيق مفتاح جلسة ثابتًا داخل `app.js`، لذلك يجب تغييره قبل النشر العام. fileciteturn41file0
